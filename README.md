# `[sel_]` — Plain-Text Vertical Selection Palette for Android

A minimal, zero-bloat (<1 MB) PopClip + Google Lens plain-text alternative for Android built with pure native views and `TYPE_ACCESSIBILITY_OVERLAY`, inspired by the clean ASCII scoreboard aesthetic of [PlainTextSports.com](https://plaintextsports.com/).

## v2.4 Highlights
- **100% Pure Plain-Text Popup Aesthetic (Zero Emojis or Bitmap Icons):**
  - The popup is rendered as a genuine plain-text ASCII sheet (`+====================================+`, `+------------------------------------+`, `CODE | LABEL`) with flat, breathable monospace rows instead of dense graphical button boxes.
  - Uses ASCII symbols (`[+]`, `[#]`, `|>`, `@#`, `<-`, `==`, `<>`, `[2C]`, `[_]`, `[*]`, `[X]`) and concise 1–4 letter codes (`CPY`, `PST`, `CUT`, `ALL`, `WEB`, `YT`, `WIKI`, `GGL`, `DDG`, `BNG`, `BRV`, `CLP`, `MD`, `DEF`, `TRN`, `MAG`, `URL`, `CLR`, `A-Z`, `Aa`, `INC`, `TTS`, `LOG`).
- **Up to 2 Extra Plain-Text Bracket Rows (`ROW 1` & `ROW 2`):**
  - Alongside `[CPY]  [PST]  [CUT]  [ALL]`, assign up to 5 tools per row into `ROW 1` and `ROW 2` (`[WEB]  [YT]  [TRN]  [INC]`).
- **External Browser Incognito Mode (`INC | INCOGNITO`):**
  - Opens your actual installed browser in Incognito / Private mode (long-press `INC` for `[sel]`'s internal zero-history WebView fallback).
