# Sel — Native PopClip Selection Bar for Android (`v4.1.0`)

A fast, native-looking, power-efficient PopClip alternative for Android built with pure Android views and `TYPE_ACCESSIBILITY_OVERLAY`.

## Highlights (`v4.1.0`)
- **Works Automatically Across Browsers & Apps**: Detects Android's native `FloatingToolbarPopup` across Chrome, Brave, Edge, Firefox, Samsung Internet, and WebViews (including system-owned floating toolbars, deep WebView/GeckoView `ACTION_COPY`, and safe single-shot Copy fallback).
- **Native Android Material Pill Attached Directly Below the System Popup**:
  - Matches Android's native `48dp` pill shape (`24dp` radius, Android 12+ Material You dynamic colors in Auto mode, native `⋮` overflow icon).
  - Docks cleanly `4dp` directly underneath Android's native Copy/Share popup (flipping smoothly above when the keyboard is open).
- **Icons-Only Mode + Auto-Fetched Favicons**:
  - Toggle **Icons Only** in `Settings` for crisp native vector icons + automatically fetched, disk-cached site favicons for every default & custom search portal (Google, DDG, Bing, Brave, YouTube, Reddit, Perplexity, ChatGPT, GitHub, Maps, Kagi, etc.).
- **Zero Bloat**: Clipboard History, Notes, and Text Grab completely removed—focused 100% on fast, reliable, context-aware selection actions (`Search`, `YT`, `★` pinned portals/tools, Phone/WA/W4B, Clean URL, QR, Magnet, Inline Math/Unit/Timestamp/Base64, Define, Translate, Extract Links, Markdown, Regex/Pipe, Speak, Per-App Mute, and JSON Backup).
